# HTML Website Collection

A curated collection of modern, responsive, and production-ready static HTML websites crafted with clean markup, rich styling, and optimized assets.

---

## 📂 Included Websites

### 1. `dentist1` — DentCare Pro (Modern Family & Dental Implant Clinic)
- **Concept:** Full-service family and implant dental clinic with a friendly, trustworthy medical aesthetic.
- **Header Style:** **Royal Elementor Theme Header Style 2** (`template-parts/headerstyle2.php` + `header-top.php`):
  - Top Bar with 24/7 emergency hotline, email, clinic address, and credentials.
  - Middle Header with clinic branding, phone badge with icon, opening hours badge, and prominent "Book Appointment" CTA button.
  - Sticky Desktop Navigation Bar with streamlined 5-item menu, treatment dropdown, and integrated live search.
- **Royal Addons Integration:**
  - `royalservices` — 6-treatment clinical cards with icon hover animations.
  - `royalimagecompare` — Interactive draggable Before & After smile makeover comparison slider.
  - `royalteam` — Specialized dentist cards with qualifications and social links.
  - `royalform` & `royalopeninghours` — Appointment booking form with validation modal and live current-day highlighted opening hours schedule.
  - `royalpricingtable` — 3-tier clear treatment packages.
  - `royalreview` — Verified 5-star patient review cards.
  - `royalaccordion` — Accessible dental FAQ accordion.

### 2. `dentist2` — LuminaSmile (Boutique Cosmetic Dentistry & Smile Architecture)
- **Concept:** High-end boutique aesthetic dental studio in Manhattan specializing in porcelain veneers, laser whitening, and Digital Smile Design (DSD).
- **Header Style:** **Royal Elementor Theme Header Style 4** (`template-parts/headerstyle4.php` + `header-top.php`):
  - Top announcement bar with complimentary 3D smile scan offer and patient portal link.
  - Modern unified inline header with gold-accented logo, concise 5-item Royal Menu, VIP "Book Consultation" action button, and right-panel icon triggers.
- **Royal Addons Integration:**
  - `royalimagecompare` — Porcelain veneer 8-unit makeover transformation slider.
  - `royaltimeline` — 4-step digital smile journey.
  - `royalteam` — Celebrity aesthetic dentists and smile architects.
  - `royalpricingtable` — Curated concierge smile membership tiers.
  - `royalform` — Private suite consultation booking with treatment selector and modal confirmation.

### 3. `dentist3` — ApexOrtho & Maxillofacial Dental Surgery Center
- **Concept:** Tri-state surgical center of excellence for robotic-guided dental implants, maxillofacial surgery, and orthodontic bite correction.
- **Header Style:** **Royal Elementor Theme Header Style 1 / 3** (`template-parts/headerstyle1.php` + `header-top.php`):
  - Emergency top bar with 24/7 acute trauma dispatch hotline and 3-branch switcher.
  - Branding header with clinic identity, board certification badges, and direct surgical coordinator phone.
  - Dedicated rich navigation bar with streamlined primary items, surgical specialties dropdown, and contrasting "Schedule Surgery" action button.
- **Royal Addons Integration:**
  - Interactive Symptom Matcher — Quick-finder widget matching symptoms to surgical/ortho solutions.
  - `royalfeatures` — Diagnostic surgical tech grid (3D CBCT, Trios Scanner, Piezosurgery, Guided Surgery).
  - `royalservices` — Advanced oral surgery & orthodontics cards.
  - `royalbrancheslocator` — Interactive tab switcher for Downtown, Midtown, and North Point surgical centers.
  - `royalform` & Emergency Triage Guide — Surgical appointment form with immediate trauma advice.

## 🚀 Getting Started

Simply open any project folder in your browser or run a lightweight local static server:

```bash
# Using Python
python -m http.server 8000

# Using PHP (Laragon)
php -S localhost:8000
```
