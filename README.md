# HTML Website Collection

A curated collection of modern, responsive, and production-ready static HTML websites crafted with clean markup, rich styling, and optimized assets.

---

## 📁 Included Websites

### 1. `creed1` — CREED (Single-Page Edition)
- **Organization:** Centre for Rehabilitation Education Earning Development (CREED)
- **Architecture:** Single-page application layout with sticky interactive navigation, hero showcase, live statistics ticker, development programs, and community impact highlights.
- **Technologies:** HTML5, CSS3, JavaScript, Font Awesome, Bootstrap Icons.

### 2. `creed2` — CREED (Multi-Page Portal)
- **Organization:** Centre for Rehabilitation Education Earning Development (CREED)
- **Architecture:** Multi-page website consisting of core pages:
  - `index.html` — Homepage featuring announcement tickers, program highlights, impact counters, and leadership profiles.
  - `contact-us.html` — Interactive contact page with head office details, interactive forms, and quick communication channels.
  - `support-us.html` — Support and donation hub with bank transfer guides and mobile banking instructions.
- **Technologies:** HTML5, CSS3, JavaScript, Bootstrap 5, Bootstrap Icons.

### 3. `MithilaPolymer` — Mithila Polymer Industries Ltd
- **Organization:** Mithila Polymer Industries Ltd
- **Architecture:** Modern B2B industrial manufacturing website with tailored corporate design tokens, comprehensive product categories, manufacturing specifications, and quotation request forms.
- **Technologies:** HTML5, Tailwind CSS, JavaScript.

### 4. `rds` — Rural Development Sangstha (RDS)
- **Organization:** Rural Development Sangstha (RDS)
- **Architecture:** NGO web portal featuring mega menu navigation, interactive slider, impact counters, sustainable livelihood & microfinance programs, health & education initiatives, and community stories.
- **Technologies:** HTML5, CSS3, JavaScript, Bootstrap 5, Bootstrap Icons.

---

## 🚀 Getting Started

Simply open any project folder in your browser or run a lightweight local static server:

```bash
# Using Python
python -m http.server 8000

# Using PHP (Laragon)
php -S localhost:8000
```
